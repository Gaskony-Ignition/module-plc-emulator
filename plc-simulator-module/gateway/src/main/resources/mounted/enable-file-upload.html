🚀 Enhanced PLC Simulator - File Upload

✅ File upload enhancement is now active! Navigate to your device configuration page.

Activation Instructions

This page will automatically activate the file upload enhancement for Enhanced PLC Simulator devices.

  1. Keep this page open
  2. Navigate to: Config → Devices
  3. Create or edit an Enhanced PLC Simulator device
  4. You should see an "📁 Upload PLC File" button above the file content textarea

What This Does

  • Adds a file browse button to the device configuration form
  • Automatically reads selected files and populates the textarea
  • Supports L5K, JSON, CSV, and XML files
  • Works alongside the existing copy/paste method
