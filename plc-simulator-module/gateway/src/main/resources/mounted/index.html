📡 Enhanced PLC Simulator

Multi-vendor PLC device simulator for Ignition SCADA

🚀 Quick Start

Import PLC files and create simulated device connections with our easy-to-use interface.

📁 Open Edit Program

📋 Workflow

  1. Create a new device connection in Config → Devices → Create Device Connection
  2. Select "Enhanced PLC Simulator" from the device type dropdown
  3. Configure device name and parser type
  4. Click Create (file is optional)
  5. Use Edit Program to import your PLC file

🚀 Quick Start Guide

  1. Step 1: Create device at Config → OPC UA → Device Connections → Create New → Enhanced PLC Simulator
  2. Step 2: Upload your PLC file (L5K, JSON, CSV)
  3. Step 3: Copy the file content and paste it into the device's "File Content" field
  4. Step 4: Save the device configuration and connect!
