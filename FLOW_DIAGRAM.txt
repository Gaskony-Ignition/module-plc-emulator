================================================================================
                      FAILURE POINTS & RECOVERY
================================================================================

FAILURE POINT [1]: prepareFile() returns NULL
├─ Cause: No file uploaded, no file path in config
├─ Status: "Ready - Waiting for file upload"
├─ Recovery: Upload file via /main/data/plcsimulator/upload endpoint
└─ Expected: Device reloads, moves to Step [3]

FAILURE POINT [2]: Parser Service unavailable
├─ Cause: Python executable not bundled, port in use, etc.
├─ Status: Logged as warning, falls back to built-in parser
├─ Recovery: Automatic - built-in parsers used
└─ Expected: Device continues with built-in parser

FAILURE POINT [3]: Parser returns NULL
├─ Cause: File format doesn't match parser type, file corrupted
├─ Status: "Error: Failed to parse file"
├─ Recovery: 
│  ├─ Verify parser type matches file format
│  ├─ Re-upload corrected file
│  └─ Check logs for parse errors
└─ Expected: Device restarts, tries again

FAILURE POINT [4]: Root node creation fails
├─ Cause: Milo framework issue, OPC-UA server problem
├─ Status: "Error: ..." message
├─ Recovery: Restart device, check OPC-UA server health
└─ Expected: Device retries on next restart

FAILURE POINT [5]: Node manager rejects nodes
├─ Cause: Duplicate node IDs, framework issue
├─ Status: Tags created but not visible in OPC-UA
├─ Recovery: Check Milo framework logs, restart device
└─ Expected: Tags appear after recovery

FAILURE POINT [6]: Zero tags in parsed JSON
├─ Cause: File is empty, parser didn't extract tags
├─ Status: "WARNING: Zero tags created"
├─ Recovery: 
│  ├─ Verify file format valid
│  ├─ Check parser type correct
│  └─ Try different parser or file
└─ Expected: Tags appear after fixing file

[✓] Device created in Gateway Config

[✓] File content is valid for selected parser type
[✓] Parser can read file (not corrupted)
[✓] Parser returns valid JSON structure
[✓] JSON contains "global_tags" or "programs" array
[✓] Each tag has "name" and "data_type" fields
[✓] Device reaches "Running" status (check via status endpoint)
[✓] Root node created (check logs)
[✓] Address space builder executed (check logs)
[✓] Total tags > 0 (check logs for warnings)
[✓] Node manager added nodes (no rejection errors)
